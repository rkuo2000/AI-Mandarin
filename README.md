## 2. 文字生成 (Text Generation)

### 提示詞的結構(Prompt Structure)
| 結構                       | 中文內容                                                                        |
| ------------------------ | --------------------------------------------------------------------------- |
| **角色（Role）**             | 你是一位經驗豐富的**網頁文字撰稿人**。                                                       |
| **任務（Task）**             | 你的任務：撰寫一篇**部落格文章**。                                                         |
| **情境（Context：主題、目標、細節）** | **主題：** 家庭預訂海灘假期。<br> **目標族群：** 有學齡兒童的家庭。                                      |
| **格式（Format）**           | **長度：**500 字，以**豐富文字格式**呈現，使用 **H2 標題**、**項目符號**、**粗體文字**。<br> **風格：** 輕鬆、乏味。 |
| **範例（Example，「少量示例」）**   | 「**預訂家庭海灘假期時，你應該考慮這些事項。**」                                                  |
